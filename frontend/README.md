# Frontend (React + Vite + TypeScript + Fluent UI + MSAL)

Generated scaffold for a Spec Driven multi-agent app UI.

## Overview
This project bootstraps a React 18 + Vite 5 + TypeScript SPA using Fluent UI components and Azure AD authentication via MSAL. It includes basic routing, theming, authentication hook, protected route guard, and an opinionated folder structure for growth.

## Tech Stack
- React 18, Vite 5, TypeScript (strict)
- Fluent UI (@fluentui/react-components) with custom theme overrides
- MSAL (@azure/msal-browser / @azure/msal-react) for Azure AD auth
- React Router v6 for navigation
- ESLint + Prettier for lint/format

## Folder Structure (src)
See in repo; key areas: auth (MSAL), routing (routes + guard), layout (shell), theme (design tokens + theme), services (http client), hooks (custom hooks), pages (route level views).

## Environment Variables (.env)
Copy `.env.example` to `.env` and fill values:
```
VITE_AAD_CLIENT_ID=<app-client-id>
VITE_AAD_TENANT_ID=<tenant-id>
VITE_AAD_REDIRECT_URI=http://localhost:5173
```

Authority is derived as: `https://login.microsoftonline.com/${VITE_AAD_TENANT_ID}`.

## Auth Flow
`PublicClientApplication` is configured in `auth/authConfig.ts`. The app wraps with `MsalProvider`. `useAuth()` exposes `login`, `logout`, `user`, `isAuthenticated`, `loading`. The `ProtectedRoute` triggers an interactive login (popup with redirect fallback) if unauthenticated.

## Theming
`theme/createTheme.ts` clones Fluent light theme and overrides brand colors; `theme/tokens.ts` centralizes design tokens. Root provider uses `<FluentProvider theme={appTheme}>`.

## Adding Pages
Create folder under `pages/<PageName>/<PageName>.tsx` and add lazy import in `routing/routes.tsx`.

## Services
Use `services/httpClient.ts` for fetch wrapper (aborts + JSON). Add feature services returning typed promises (avoid direct fetch in components/pages).
